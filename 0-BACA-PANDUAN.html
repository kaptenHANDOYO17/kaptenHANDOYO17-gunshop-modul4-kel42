Bore & Barrel: dari zip sampai online di Vercel

Semua kode dari modul sudah terpasang di folder ini, sama persis dengan repo Redzzaja/PWA1_PrakPPB. Kamu tidak perlu mengetik kode apa pun. Tugasmu cuma double-click 4 file dan klik beberapa tombol di GitHub dan Vercel. Total sekitar 15–20 menit.

1

Buka folder proyek

  1. Buka File Explorer → Downloads → folder gunshop-modul4-siap.
  2. Folder ini sudah ditaruh Claude langsung di laptopmu, jadi tidak perlu ekstrak zip apa pun. Semua langkah berikutnya dilakukan di folder ini.

Pakai folder gunshop-modul4-siap, bukan hasil ekstrak zip yang lama. File dari zip hasil download ditandai “dari internet” dan diblokir Smart App Control.

2

Double-click 1-INSTALL.bat

Sekali saja · 2–5 menit, tergantung internet

  1. Double-click 1-INSTALL (ikonnya roda gigi). Jendela hitam akan terbuka.
  2. Kalau muncul layar biru “Windows protected your PC”, klik tulisan More info lalu Run anyway.
  3. Kalau muncul “Do you want to allow this app to make changes?”, klik Yes. Ini muncul saat Node.js atau Git dipasang.
  4. Tunggu sampai tertulis SELESAI. Install berhasil. lalu tekan tombol apa saja untuk menutup.

Masih muncul “Smart App Control blocked…”? Klik Okay, lalu pakai cara manual: klik kanan area kosong di dalam folder → Open in Terminal, lalu ketik perintah ini satu per satu dan tekan Enter. Kalau muncul “'npm' is not recognized”, pasang Node.js dari nodejs.org dulu (Windows Installer .msi, Next terus), tutup terminal, lalu buka lagi.

Installnpm.cmd install
Jalankannpx.cmd vite --open
Tes HPnpm.cmd run build; npx.cmd vite preview --host

Skrip ini mengecek Node.js (Vite 8 butuh versi 20.19+ atau 22.12+) dan Git, memasangnya otomatis kalau belum ada, lalu menjalankan npm install. Perintah npm install -D vite-plugin-pwa dari modul sudah termasuk.

3

Double-click 2-JALANKAN.bat

Setara dengan npm run dev di modul

  1. Double-click 2-JALANKAN. Browser akan terbuka sendiri ke localhost:5173 dan menampilkan toko Bore & Barrel.
  2. Coba klik menu Catalog, About, Contact, dan klik salah satu kartu senjata untuk membuka popup.
  3. Cek Service Worker (untuk laporan): tekan F12 → klik tab Application (bahasa Indonesia: Aplikasi; kalau tidak terlihat, klik ») → di kiri klik Service workers. Statusnya harus activated and is running. Kalau belum, klik Start (Mulai).
  4. Selesai mencoba, tutup jendela hitamnya (klik X).

Jangan tutup jendela hitam selama web masih dipakai. Menutupnya sama dengan mematikan web.

4

Tes di HP: double-click 3-TES-DI-HP.bat

Setara dengan npm run build lalu npm run preview -- --host

  1. Pastikan HP dan laptop tersambung ke WiFi yang sama.
  2. Double-click 3-TES-DI-HP. Kalau muncul jendela Windows Firewall, klik Allow access.
  3. Di jendela hitam, cari baris Network: misalnya http://192.168.1.7:4173/.
  4. Ketik alamat itu persis di Chrome HP. Toko akan tampil versi mobile.

Tampilan bisa dicek lewat alamat WiFi ini, tapi fitur Install app dan offline di HP butuh HTTPS. Keduanya baru jalan setelah web online di Vercel (langkah 7).

5

Buat repo kosong di GitHub

Di browser · 1 menit

  1. Buka github.com/new dan login. Belum punya akun? Klik Sign up dulu.
  2. Di kolom Repository name ketik nama repo. Ganti xx dengan nomor kelompokmu:
    Ketikgunshop-modul4-kelxx
  3. Pilih Public.
  4. Biarkan “Add README” tetap mati (Off), dan jangan tambahkan .gitignore atau license. Repo harus kosong.
  5. Klik tombol hijau Create repository.
  6. Di halaman berikutnya, bagian Quick setup, pastikan HTTPS terpilih, lalu klik ikon copy (dua kotak) di ujung kanan link. Link-nya seperti https://github.com/namakamu/gunshop-modul4-kelxx.git.
6

Double-click 4-UPLOAD-KE-GITHUB.bat

Push ke GitHub · 1–2 menit

  1. Double-click 4-UPLOAD-KE-GITHUB.
  2. Hanya pertama kali: ketik namamu lalu Enter, kemudian ketik email akun GitHubmu lalu Enter.
  3. Saat diminta Link repo, tekan Ctrl + V (atau klik kanan) untuk menempel link dari langkah 5, lalu Enter.
  4. Muncul jendela Connect to GitHub: klik Sign in with your browser. Di browser, klik tombol hijau Authorize git-ecosystem.
  5. Tunggu sampai tertulis BERHASIL. Halaman repo akan terbuka dan semua file sudah ada di sana.

Kalau nanti kamu mengubah kode, cukup double-click file ini lagi. Link tidak ditanya lagi, dan Vercel otomatis memperbarui web-nya.

7

Upload ke Vercel

Di browser · 2–3 menit

  1. Buka vercel.com/signup. Pilih I'm working on personal projects (Hobby), isi nama, klik Continue, lalu Continue with GitHub dan klik Authorize. Sudah punya akun? Langsung Log in → Continue with GitHub.
  2. Di dashboard, klik Add New… (pojok kanan atas) → Project.
  3. Di kotak Import Git Repository, cari gunshop-modul4-kelxx lalu klik Import di sebelahnya.
    Repo tidak muncul? Klik Install atau Adjust GitHub App Permissions, pilih All repositories, klik Save, lalu kembali.
  4. Di halaman Configure Project, cek Framework Preset sudah Vite (biasanya otomatis). Yang lain jangan diubah.
  5. Klik Deploy. Tunggu sekitar 1 menit. Kalau mau, klik Build Logs untuk melihat output terminalnya (diminta di modul).
  6. Muncul Congratulations! Klik Continue to Dashboard. Link web kamu ada di bagian Domains, bentuknya gunshop-modul4-kelxx.vercel.app.
  7. Buka link itu di Chrome HP → menu ⋮ → Add to Home screen / Install app. Aplikasi sekarang punya ikon di layar HP.

Kalau ada masalah

“'npm' is not recognized…”Node.js baru terpasang tapi Windows belum sadar. Restart laptop, lalu double-click 1-INSTALL.bat lagi.
Jendela hitam langsung tertutupFolder belum diekstrak. Ulangi langkah 1.
Winget tidak ada / Node gagal dipasang otomatisSkrip akan membuka nodejs.org. Download Windows Installer (.msi), klik Next sampai Finish, lalu jalankan 1-INSTALL.bat lagi.
HP tidak bisa membuka alamat NetworkPastikan WiFi sama (bukan data seluler), dan klik Allow access di Windows Firewall. WiFi kampus kadang memblokir antar-perangkat; coba hotspot dari HP ke laptop.
Upload GitHub gagal, ditanya “Timpa isi repo?”Repo kamu tidak kosong (ada README). Tekan Y supaya isinya diganti proyek ini.
Salah menempel link repoSkrip otomatis menghapus link yang gagal. Double-click 4-UPLOAD-KE-GITHUB.bat lagi dan tempel link yang benar.
Vercel: Build failedBuka Settings → Build and Deployment, pastikan Framework Preset Vite, lalu Redeploy.
